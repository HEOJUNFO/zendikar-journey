# 세계관 (world/)

젠디카르 카드를 한 장씩 받아 세계관에 추가하며 쌓아가는 곳. 게임(저장소 루트)은 이 폴더를 원본으로 읽는다.

## 흐름: 카드 1장 → 세계관

1. **카드 기록**: `cards/<세트>-<번호>.md` 에 카드 원문(이름, 비용, 타입, 규칙 텍스트, 플레이버 텍스트)을 그대로 남긴다.
2. **해석**: 이 카드가 우리 세계에 무엇을 더하는지 정리하고, 사용자 확인을 받는다. 카드 파일의 `## 해석` 에 항목마다 출처를 붙인다: [카드] 텍스트와 카드 정보, [그림] 일러스트, [배경] 카드 밖 MTG 배경지식, [가공] 게임을 위해 정한 것. 카드 밖 설정도 쓸 수 있지만 출처를 숨기지 않는다.
3. **요소 반영**: 새 요소는 `entities/<종류>/` 에 파일을 만들고, 기존 요소는 내용을 보강한다. 카드 파일의 `entities` 에 반영한 요소 id를 적는다. 지역이 필요한 카드면 location 에 `map` 을 달고 `npm run world:map` 을 실행한다. 게임에서 움직여야 하는 인물과 사건에는 `sim` 을 단다.
4. **검사**: `npm run world:check` 로 형식과 참조를 확인한다.
5. **비교표**: [`card-effects.md`](card-effects.md) 에 카드 효과와 게임 구현을 나란히 적는다. 규칙을 바꾸면 이 표도 고친다.

## 카드 타입 → 요소 종류 (기본 대응)

| 카드 | 요소 종류 | 폴더 |
|---|---|---|
| 대지 | 장소 (지역, 자원) | `locations/` |
| 생물 | 생물종/몬스터 | `creatures/` |
| 전설적 생물, 플레인즈워커 | 인물 (NPC) | `characters/` |
| 부족/세력이 드러나는 카드 | 세력 | `factions/` |
| 마법물체, 장비 | 아이템 | `items/` |
| 순간마법, 집중마법 | 주문 (배워서 쓰는 것), 사건 (세계에 일어나는 것, 예: 함정) | `spells/`, `events/` |
| 부여마법, 세계 규칙이 드러나는 카드 | 세계의 법칙 | `laws/` |

대응은 기본값일 뿐이다. 카드 한 장이 여러 요소를 만들거나 기존 요소를 보강만 할 수도 있다.

## MTG 규칙 → 게임 대응

카드의 규칙 텍스트를 게임으로 옮길 때 쓰는 기준. 새 개념이 나오면 사용자와 정하고 여기에 더한다.

| MTG | 게임 |
|---|---|
| 대지 | 지역 (location 하나). 대지 카드 한 장이 지역 하나가 된다 |
| 대지가 내 통제 아래 들어온다 (상륙) | 그 땅과 **유대를 맺는다** (4시간, 하루에 한 땅 = 턴당 대지 1장). NPC는 LLM이 짠 하루의 `bond` 블록으로. 짐승은 최근 사냥터 하나만 가진다 |
| "+N/+N until end of turn" | 그날 00:00까지 공격력/방어력이 오른다 (`boost`). 상륙으로 오르는 것은 인물의 `sim.landfall` |
| 돌진 (trample) | 상대를 죽이고도 남는 피해가 같은 곳의 다른 누군가(무작위)에게 넘어간다 |
| 대지의 색 | 지역의 `map.color`, 없으면 지형으로 정한다 (화산·바위 적, 공중섬·초원 백, 숲 녹, 바다·해변 청, 늪 흑, 정착지 무색) |
| "{T}: Add {B} or {R}" | 두 색 땅 `map.color: [B, R]`. 하루 마나 1을 쓸 때 둘 중 필요한 색으로 (`B/R`) |
| 대지가 탭된 채 들어온다 | 유대를 맺은 그날은 그 땅의 마나가 나오지 않는다 (location `sim.enters_tapped`). 땅이 모두에게 묶이지는 않는다 |
| "이 대지가 들어올 때" | 누군가 그 땅과 유대를 맺을 때 (location `sim.on_bond`) |
| 기본 대지 종류 (산, 평원, 섬, 늪, 숲) | 지형으로: 바위·화산 산, 초원·설원 평원, 해변·강 섬, 늪 늪, 숲 숲. 이름 있는 대지 카드(`sim.nonbasic`)는 종류가 없다 |
| 마나 능력이 없는 대지 | `sim.no_mana`. 유대는 맺지만 마나를 내지 않는다 |
| "당신의 무덤에 있는 생물 카드" | 그 이를 섬기다 죽은 권속 (`Actor.fallen`). 생물의 색은 `colors`, 없으면 마나 색 |
| "{2}, {T}: 무덤의 흑색 생물마다 {B}" | location `sim.fallen_mana: { color, cost }`. 그 땅은 하루 max(1, N − cost)를 낸다 (순이익으로 단순화) |
| 턴을 건너뛴다 / 추가 턴 (마고시) | 턴 = 하루. 건너뛴 날과 남의 추가 턴인 날은 "시간 밖"(`outOfTime`): 제자리에 서서 아무것도 안 하고, 누구도 닿지 않으며, 시간이 그를 건드리지 않는다. 추가 턴 = 그 사람만 움직이는 하루 (`state.extraDays`, `sim/eons.ts`) |
| "대상 플레이어" (피라냐 습지의 생명 잃기) | 그 자리에 함께 있는 누구든 (짐승도, 자신은 빼고). 플레이어는 행동할 때 고르고, NPC는 LLM이 고른다 (`sim/llm/choose.ts`). 아무도 없으면 헛된다 |
| "산이 당신의 통제 아래 들어올 때마다, 다른 산이 다섯 이상이면 대상에게 피해 3" (발라쿠트) | 발라쿠트를 쥔 이가 산(기본 땅)과 유대를 맺을 때(페치 포함) 다른 산 5곳 이상이면, 발라쿠트가 있는 지역(과 구역) 어디의 누구든 하나에게 피해 3. 안 줄 수도 있다 (`sim.mountain_fire`) |
| "대상 생물이 턴 끝까지 +2/+0" (흔들리는 봉우리) | 그 자리의 하나(자신도, 짐승도)가 00:00까지 그만큼 강해진다 (`Actor.pumps`). 상륙 기세와 따로 쌓인다 |
| "대상 생물이 턴 끝까지 비행" (바다절벽) | 그 자리의 하나(자기 자신도, 짐승도)가 00:00까지 그 능력을 얻는다 (`Actor.granted`). 고르는 방식은 "대상 플레이어"와 같다 |
| "이번 턴에 전장에 들어온 생물" | 오늘 세상에 새로 나온 생물: 함정·능력으로 태어난 것, 되살아난 것 (`Actor.enteredAt`). 처음부터 있던 이는 들지 않는다 |
| +1/+1 카운터 | 죽을 때까지 남는 +1/+1 (`Actor.plusCounters`, `ptOf` 가 더함). 되살아나면 없어진다 |
| {T}를 비용으로 쓰는 땅의 능력 | 그날 그 땅은 마나를 내지 않는다 (`Actor.landsTapped`). 이미 그 땅의 마나를 썼으면 쓸 수 없다 |
| 유지 단계 ("At the beginning of your upkeep") | 매일 00:00 (턴이 시작될 때) |
| "무덤의 생물 카드를 전장으로" | 그 이를 섬기다 죽은 권속 하나가 되살아나 다시 권속이 된다 (가장 최근에 죽은 이) |
| 대지를 희생 | 그 이의 그 땅과의 유대가 끊긴다. 땅은 세계에 남는다 |
| "서고에서 대지를 찾아 전장에" (페치) | 그 종류의 땅 가운데 아직 유대 없는 곳 하나와 멀리서 유대를 맺는다. 하루 한 땅에 들지 않고 상륙으로 친다. 플레이어도 NPC(LLM 계획의 `fetch` 블록)도 쓴다. 서고를 섞는 것과 덱 압축은 아직 없다 (찾아온 땅은 `fetched` 에 기록) |
| 마나 | 카드에서 온 존재: 카드의 마나 값만큼 카드의 색으로 (`sim.mana`). 플레이어: 유대를 맺은 땅 하나마다 그 색 1. 모두 00:00에 다시 찬다. 부서지거나 탭된 땅은 마나를 내지 않는다 |
| 비용 ("pay {X}", "{B}{B}{B}, {T}:") | 마나를 치른다. {T}는 쓴 이가 00:00까지 탭된다 (하루 한 번) |
| 토큰 | 게임 안에서 새로 생기는 인물 (카드 파일 없음). 보통 만든 이의 권속이 된다. 카드가 정한 색을 지닌다 (만드는 효과의 `colors`, 무색이면 `[]`, 반드시 적는다) |
| 당신이 통제하는 생물 ("you control") | 당신의 **권속** (`law-retainers`). 주인 곁을 따르고, 주인의 싸움에 함께 나서고, 주인이 부릴(탭할) 수 있다. 플레이어는 대화로 설득해 얻는다 |
| 턴 ("이번 턴에") | 게임 하루 (00:00~24:00) |
| 대지 파괴 | 그 지역이 모두에게 부서진다. 7일 뒤 00:00에 되살아난다 (`DESTROYED_DAYS`, [결정] 2026-09-30). 그동안 유대도 마나도 땅의 능력도 없고, 탐색도 일도 할 수 없다. 이미 맺은 유대는 남아 있어 되살아나면 다시 마나를 낸다 |
| 탭 (인물) | 묶인다. 움직이지도 행동하지도 못한다 |
| 탭 (대지) | 그 땅을 잠시 쓸 수 없다 (탐색·일 불가). 오가는 것은 된다 |
| 언탭 | 턴이 시작될 때 (00:00) 풀린다. "다음 언탭 단에 언탭되지 않는다" = 모레 00:00 |
| 공격력/방어력 (P/T) | 인물의 `sim.pt`. 카드 값 그대로. 플레이어는 1/1에서 시작 |
| 피해 N | 방어력에 쌓인다. 쌓인 피해가 방어력 이상이면 죽는다. 쌓인 피해는 턴이 끝날 때(00:00) 사라진다 |
| 죽음 | NPC는 세계에서 사라지고, 플레이어는 인생이 끝난다. 단 플레이어가 끼지 않은 싸움은 죽이지 않고 4시간 기절시킨다 (싸움은 거기서 끝) |
| 전투 | 1시간에 한 합. 양쪽이 동시에 공격력만큼 피해를 준다. 탭된(묶인) 쪽은 반격하지 못한다. 공격받은 NPC는 그날 공격자를 적으로 삼아 계속 싸운다 |
| 비행 | 비행하지 못하는 자에게 공격받으면 날아올라 피할 수 있다 (피할지는 그 인물이 정한다) |
| 공격 ("attacks") | 인물: 플레이어의 공격 행동, 또는 대화 중 NPC가 적의를 드러냄. 해안을 덮치는 존재(로르토스): 아침 LLM이 고르는 사건 |
| 생명 ("loses/gains N life") | 기력에 얹는다. 생명 1 = 기력 10 (`sim/life.ts`). 잃어도 죽지 않고, 기력이 0이면 쓰러진다. 피해가 아니라서 조심해도 못 피한다 |
| "이번 턴에 생명을 얻었으면" | 그날 생명을 주는 효과를 받았으면. 잠과 식사로 차는 기력은 생명이 아니다 |
| 함정의 대체 비용 조건 ("If …, you may pay {B} rather than …") | 함정 사건의 발동 조건. 조건이 맞으면 반드시 발동하고, 온전한 값을 치를 주인은 없다 |
| 오라 ("Enchant creature") | 한 사람에게 거는, 그가 죽을 때까지 남는 주문 (`aura`) |
| "플레이어에게 전투 피해를 줄 때" | 싸움에서 누군가에게 피해를 줄 때 |
| "그것의 통제자" | 권속이면 그 주인, 아니면 자신 |
| 주문 (순간마법, 집중마법) | 배우는 곳에서 익혀 두고, 마나를 치러 1시간 들여 건다. 대상 "상대"는 같은 곳에 있는 다른 이. 맞은 NPC는 그날 시전자를 적으로 삼는다 |
| 킥커 ("tap an untapped X you control") | 시전자의 권속 중 X인 이 하나를 00:00까지 탭하고 더한 효과를 얻는다 |
| 마법물체 (artifact) | 아이템 (`items/`). 한곳에 서 있고, 그곳에서 값을 치르고 1시간 들여 **길들인** 이의 것이 된다 (플레이어, NPC). 주인이 죽거나 떠나면 다시 주인 없는 것 |
| "들어올 때 X 충전 카운터" | 길들일 때 그릇에 담기는 값 (`state.items`의 `counters`) |
| "생명이 N이 된다" | 기력을 N×10으로. "may"면 이득일 때만 |
| 지속물 (permanent) | 세계에 남아 누군가에게 속한 것 (`law-permanents`): 땅, 부여마법(오라), 마법물체(아이템), 생물(인물). 플레인즈워커는 아니다 |
| "생물 아닌 지속물이 파괴되면" | 그 땅에 있는 생물 아닌 지속물(지금은 땅 자체)이 남의 손에 부서질 때 (`trigger: destroyed`) |
| 플레인즈워커 | 차원을 넘나드는 인물 (`law-planeswalkers`). 다른 인물처럼 LLM이 하루를 짜고, 능력은 아침 LLM이 고른다 |
| 충성도 | 기세 (`sim.loyalty`). +N 능력은 올리고 −N 능력은 쓴다. 하루에 하나. 피해는 기세에서 빠지고, 0이면 이 차원을 떠난다 (죽음 아님) |
| 손패 / 버리기 / 무덤 / 뽑기 | 지닌(아는) 주문 / 주문을 잊음 / 잊은 주문 / 세계의 주문을 무작위로 떠올림 |
| "각 플레이어" | 그 자리에 있는 모두 |
| 주문의 색 | 비용에 든 색 |
| 생물이 전장에 들어올 때 ("As ~ enters") | 그 인물이 그날 처음 싸움에 들 때 (이오나의 색 고르기) |
| "당신의 상대" | 그날 그와 싸우는 이: 그의 적, 그를 적으로 삼은 이 (00:00까지) |
| "상대는 그 색 주문을 쓸 수 없다" | 그 상대는 어디서든 그 색 주문을 쓰지 못한다. 값 없이 쓰는 것도 (character `sim.seal`, `sim/seal.ts`) |
| 주문, 마법 | 아직 없음. 마법 카드가 나올 때 정한다 (마나는 있다) |
| 색 | 마법의 다섯 색 (`law-mana-colors`) |

## 지도

젠디카르 행성은 **망망대해에서 시작**한다. 카드로 지역이 생길 때마다 그 location 에 `map` 을 달면 지도에 지역(노드)이 하나 생긴다.

```yaml
map: { x: 96, y: 72, terrain: forest }
```

- `x`, `y`: 지도 위 위치. 지도 크기는 480×360 (x 0..479, y 0..359). 웹 지도는 처음에 땅이 있는 곳에 맞춰 보여 주고, 휠로 확대·축소, 끌어서 옮길 수 있다. 두 지역 사이의 이동 시간은 거리 ÷ 8 시간이다 (올림, 최소 1시간).
- `size`: 선택. 지도에 그리는 크기. `continent`(대륙, 큰 원) | `island`(대륙에 딸린 작은 섬, 작은 원). 없으면 구역을 가진 지역은 중간 원, 아니면 작은 노드. 작은 섬은 구역이 하나 늘 때마다 조금 커진다.
- 지도에서 땅은 마나 색으로 칠한다 (백 크림색, 청 파랑, 흑 검정, 적 빨강, 녹 초록, 마나 없음·무색은 회색, 두 색 땅은 반반). 지형은 이름 아래 글로 적는다.
- 구역의 `order`: 선택. 지역의 원 안에서 구역이 놓이는 순서 (작을수록 동쪽, 기본 0). 예: 온두는 메사 0(동), 턴팀버 1(남), 그레이펠트 2(서).
- `of`: 선택. 섬이 딸린 대륙의 id (예: 아게딤은 `of: loc-ondu`). 지도에서 대륙과 섬을 얕은 바다로 이어 그리고, 섬의 이름은 대륙 반대쪽에 쓴다. 게임 규칙에는 영향이 없다.
- `joins`: 선택. 두 지역 사이에 놓인 땅이 잇는 두 지역의 id (예: 푸른 지하묘지는 `joins: [loc-guul-draz, loc-bala-ged]`). 지도에서 두 지역을 이 땅을 지나는 땅줄기로 이어 그린다. 게임 규칙에는 영향이 없다 (이동은 여느 때처럼 거리로).
- `terrain`: `grassland` | `forest` | `rocky` | `beach` | `settlement` | `sky` | `volcanic` | `swamp` | `ruins` | `river` | `tundra` | `deepsea`. (`ruins` 폐허: 기본 색 없음, 기본 대지 종류 없음. `river` 강·폭포: 청색, 섬. `tundra` 설원: 백색, 평원)
  - `sky` 는 공중섬이다. 비행(`fly`)할 수 있는 이만 오가고 머물 수 있다. 오를 길이 있는 곳(`sim.climb_hours`, 예: 에메리아)은 비행하지 못해도 그만큼 더 들여 오른다.
  - `deepsea` 는 바다 지역이다. 물에 사는 이(`aquatic`)만 머물 수 있고, 다른 이는 들어가거나 지나갈 수 없다. 바다에서 시작하는 사건의 기준점이 된다.
  - 정글, 설원처럼 젠디카르다운 다른 지형은 해당 카드가 나올 때 `sim/world.ts` 의 `TERRAINS` 에 더한다.
- **구역**: (지도에서는 지역이 큰 원, 그 안의 구역이 작은 원으로 그려진다) 지역 안의 작은 땅은 `map: { in: loc-guul-draz, terrain: swamp }` 로 적는다 (좌표 없음, 부모 지역의 자리). 구역도 땅 하나다: 유대, 탭, 파괴가 따로 붙는다.
  - 같은 지역 안(바깥과 구역, 구역끼리)은 1시간. 다른 지역에서 구역으로 오가면 지역까지의 길에 1시간이 더 든다.
  - 만남, 대화, 전투는 같은 구역 안에서만 한다. 인물 모드에서는 자기가 있는 구역만 보인다.
  - 지역에 일어나는 사건은 그 안의 구역까지 미친다. 구역에 일어나는 사건(`range: 0`)은 그 구역에만.
  - 구역 안에 구역은 둘 수 없고, 바다에는 구역을 둘 수 없다.
- 지역 사이에는 길이 따로 없다. 막히지 않았으면 거리만큼 걸려 오간다. 배, 항로, 다리처럼 이동 수단이나 경로를 주는 카드가 나오면 그때 규칙을 더한다.

땅이 스스로 하는 일(탭된 채 들어옴, 유대를 맺을 때의 효과)은 location 의 `sim` 에 적는다.

```yaml
map: { in: loc-akoum, terrain: settlement, color: [B, R] }   # 두 색 중 하나를 내는 땅
sim:
  enters_tapped: true                    # 유대를 맺은 그날은 마나를 내지 않는다
  on_bond:
    - { type: gain_life, amount: 1 }     # 유대를 맺으면 생명 1
  # nonbasic: true                      # 이름 있는 대지 카드: 산·평원 같은 기본 종류가 없다
  # no_mana: true                       # 마나를 내지 않는다
  # fetch: { types: [mountain, plains], life: 1 }  # 내어 주고 생명 N: 그 종류 땅과 멀리서 유대
  # fallen_mana: { color: B, cost: 2 }  # 거느리다 죽은 그 색 권속 N마다: 하루 max(1, N − 2)
  # climb_hours: 6                      # 지형이 요구하는 능력(비행) 없이도 오를 수 있다. 오갈 때마다 N시간 더
  # upkeep_revive: { plains: 7 }        # 00:00에 평원 N곳 이상이면 죽은 권속 하나가 되살아난다
  # on_bond: [{ type: lose_life, amount: 1 }]  # 유대를 맺을 때 곁의 한 사람(맺는 이가 고름)이 생명을 잃는다
  # on_bond: [{ type: pump, pt: [2, 0] }]      # 유대를 맺을 때 곁의 하나(자신도, 맺는 이가 고름)가 00:00까지 +2/+0
  # on_bond: [{ type: grant, ability: fly }]    # 유대를 맺을 때 곁의 하나(자신도, 맺는 이가 고름)가 00:00까지 비행
  # grow_entered: { color: G }         # 탭하면 오늘 새로 나온 그 색 생물 모두에게 +1/+1 카운터 (오란리프)
  # mountain_fire: { others: 5, damage: 3 }  # 쥔 이가 산과 유대를 맺을 때 다른 산이 N 이상이면, 이 땅의 지역 어디의 누구에게 피해 D (발라쿠트)
  # eon: { cost: "{U}" }               # 날을 맡기는 땅 (마고시): 탭+비용으로 하루를 맡겨 내일을 잃고, 탭+유대 끊기로 되찾아 세상이 멈춘 하루를 얻는다
```

`npm run world:map` 은 미리보기 `world/map.svg` 를 다시 그린다. 게임은 요소 파일을 직접 읽으므로 생성해야 하는 파일은 없다.

## 게임 데이터 (`sim`)

게임(`sim/`)은 `status: canon` 인 요소만 읽는다. 인물과 사건은 frontmatter 의 `sim` 블록이 있어야 게임에서 움직인다. 형식은 `sim/world.ts` 의 zod 스키마가 정하고, `npm run world:check` 가 검사한다.

**인물** (`character`): NPC. 적어 두는 일과는 없다. 하루는 LLM이 성격(`persona`), 목표, 역할, 상태, 소식으로 날마다 짠다 ([결정] 2026-09-30).

```yaml
sim:
  pt: [7, 7]                  # 공격력/방어력. 카드 값 그대로
  role: 에메리아를 지키는 천사 수호자
  home: loc-emeria            # 시작 지역
  persona: >-                 # 성격, 말투, 외모. LLM이 이 인물을 연기할 때 쓴다
    ...
  goal: 에메리아와 그곳을 찾는 의로운 이들을 지킨다.
  abilities: [fly]            # 선택. 지금은 fly 만 있다
  needs: [energy]             # 선택. 쓰는 스탯 (energy, hunger, coin). 기본은 셋 다
```

인물의 `sim` 에는 선택으로 `mana: { W: 9 }` (카드의 마나 값과 색)를 단다. 그 밖의 선택 항목:

- `landfall: { pt: [4, 4], trample: true }`: 땅과 유대를 맺으면 그날 00:00까지 +P/+T (와 돌진).
- `beast: true`: 짐승. 말을 하지 않고, 배고픔 60 이상이면 같은 곳의 가장 약한 이를 덮치며(잡아먹으면 배고픔 -60), 사냥(`eat`)한 땅은 72시간 "사냥감이 바닥남"이 되어 다시 사냥터로 삼지 못한다.
- `abilities: [aquatic]`: 물에 사는 이. 바다에만 머문다 (로르토스).
- `needs: []`: 지치지도 굶지도 않는다. 생명을 잃지도 얻지도 않는다.

생물종(`creature`)에도 같은 `sim` 을 달 수 있다. 그 종의 한 개체가 세계에 산다 (예: `cre-baloth`).

능력을 지닌 인물(예: 칼리타스, 찬드라)은 `activated` 에 능력을 적는다. 쓸지, 누구에게 쓸지는 아침 LLM(`sim/llm/gm.ts`)이 정한다. 죽으면 능력도, 그가 치러야 하는 사건(`cost.by`)도 끝난다. 이런 인물은 말로 설득해 권속으로 삼을 수 없고, 짐승이 덮치지 않는다.

색 하나를 봉인하는 인물(이오나)은 `seal: true` 를 더한다. 그날 처음 싸움에 들 때 LLM이 색을 고르고, 맞선 이는 00:00까지 그 색 주문을 못 쓴다.

플레인즈워커는 `loyalty: 5`(기세)와 `knows_colors: [R]`(그 색의 주문을 모두 지님)를 더하고, 능력에 `loyalty: 1`/`-2`(충성도 능력, 비용 없음)을 적는다. 대상이 없는 능력은 `target: false`. 능력 효과: `destroy`, `raise`, `discard_spell {if_color, damage}`(지닌 주문 하나를 잊고, 그 색이면 대상에게 피해), `wheel {draw}`(그 자리의 모두가 주문을 잊고 무작위로 N개 떠올림), `flashback {color}`(잊은 그 색 주문을 대상에게 값 없이).

```yaml
sim:
  home: loc-ghet-estate       # 거처 (처음 있는 곳)
  pt: [5, 5]
  mana: { B: 7 }
  role: ...
  persona: ...
  goal: ...
  needs: []
  activated:                  # 아침 LLM이 쓸지, 누구에게 쓸지 정한다 (대상: 살아 있는 인물 하나)
    - id: blood-kin
      name: 죽여서 혈족으로 들이기
      cost: "{B}{B}{B}"
      tap: true               # 쓰면 00:00까지 탭된다
      effects:
        - { type: destroy }                                           # 대상이 죽는다
        - { type: raise, creature: cre-vampire, faction: fac-ghet, colors: [B] }  # 그렇게 죽으면 같은 P/T의 흑색 흡혈귀로 되살아나 그의 권속이 된다
```

LLM이 짜는 하루의 블록 종류는 `sleep`(잠), `eat`(식사), `work`(일), `social`(사람 만나기), `leisure`(여가), `bond`(땅과 유대 맺기, 4시간, 하루 한 땅), `claim`(주인 없는 아이템 길들이기, 1시간, 길들일 수 있는 것이 있는 날만), `store_day`·`spend_day`(마고시에 하루 맡기기·되찾기, 1시간), `grow`(오란리프, 1시간), `fetch`(쥔 페치랜드를 내어 주고 블록의 `land` 와 멀리서 유대, 1시간, 찾을 땅이 있는 날만), `learn`(블록의 `spell` 을 배우는 곳에서 익히기, 짐승은 못 함), `cast`(쥔 `spell` 을 1시간 준비해 그 자리의 누군가에게, 마나를 낼 수 있는 날만)이다. 땅의 힘을 쓰는 블록은 그 땅을 쥔 날만 열린다. `needs` 에 hunger 가 없으면 `eat` 은 쓸 수 없다. 스탯 변화는 `sim/rules.ts` 에 있다. LLM이 하루를 내지 못하면 세계는 멈추고, 다시 진행할 때 다시 묻는다 ([결정] 2026-09-30).

**사건** (`event`): 아침 LLM이 일으키거나, 누군가 어떤 땅에 상륙할 때 일어나는 일.

```yaml
sim:
  region: loc-lava-chasm      # 일어나는 곳
  range: 0                    # 이 거리 안의 땅이 영향을 받는다 (0 = 그 지역만)
  trigger: landfall           # gm | landfall | enter | destroyed (이 땅의 지속물이 남의 손에 부서질 때)
  landfalls: 2                # landfall: 누군가 이 땅과 유대를 맺었고, 그것이 그날 N번째(이상) 상륙일 때 발동
  # gained_life: true         # enter: 누군가 이 지역(구역이면 그 구역)에 들어올 때 발동. true면 그날 생명을 얻은 이만
  # cost: { by: chr-lorthos, mana: "{8}" }  # 선택. 그가 이 마나를 치러야 효과가 난다
  # chance: 0.03              # gm: 아침 LLM이 참고하는 빈도 (며칠에 한 번꼴)
  cooldown_hours: 72          # 한 번 일어난 뒤 쉬는 시간
  scope: region               # region: 그곳에 있는 이만 앎 / world: 모두가 앎
  omen: 땅이 울린다.           # 선택. 1시간 전에 오는 전조. 조심스러운 이는 damage·stat 효과를 피한다
  text: 용암 덩어리가 굴러 내려왔다.
  effects:
    - { type: damage, amount: 4 }                                  # 그곳에 있는 모든 생물에게 피해 (방어력에 쌓임)
    - { type: stat, energy: -20 }                                  # 그곳에 있는 모두의 스탯 변화
    - { type: tap, max: 8, skip_untap: true, land_label: 조수에 잠긴 해안 }  # 인물 먼저, 남으면 땅까지 최대 N개 탭
    - { type: condition, label: 무너진 길, hours: 48, blocks_travel: true }  # 지역에 남는 상태
    - { type: destroy_lands, count: 2 }                            # 대지 파괴(7일): 발동시킨 이가 그날 상륙한 땅 최근 N곳 (landfall 사건만)
    - { type: lose_life, amount: 5 }                               # 발동시킨 이만 생명 N을 잃는다 (landfall, enter 사건만)
    - { type: create, creature: cre-snake, count: 4, pt: [1, 1], colors: [G] }  # 그 자리에 주인 없는 녹색 생물 N (토큰). 그날 일으킨 자를 적으로 삼는다
```

효과 종류가 모자라면 카드에 맞춰 `sim/world.ts`(스키마)와 `sim/step.ts`(적용)에 더한다.

**주문** (`spell`): 배워서 쓰는 마법 (`sim/spells.ts`). 플레이어는 행동으로, NPC는 LLM이 짠 하루의 `learn`·`cast` 블록으로 배우고 쓴다 (NPC가 누구에게 걸지는 시전 때 LLM이 고른다).

```yaml
sim:
  cost: "{4}{B}{B}"
  speed: sorcery              # sorcery | instant (아직 차이 없음)
  learn_at: loc-malakir       # 배우는 곳. 여기서 "배우기" 행동으로 익힌다
  learn_hours: 4
  target: other_here          # other_here: 같은 곳의 다른 이 하나 / any_here: 자신 포함
  kicker: { tap: cre-vampire } # 선택. 시전자가 부리는 이 종류의 생물을 탭하면 킥커
  effects:
    - { type: lose_half_life }                 # 대상이 생명의 절반(올림)을 잃는다
    - { type: gain_life_lost, if_kicked: true } # 잃은 만큼 시전자가 얻는다 (킥커일 때만)
    # - { type: aura, pt: [3, 3], double_life_on_hit: true }  # 오라: 죽을 때까지 남는다. 입은 이가 싸움에서 피해를 주면 그를 부리는 이의 생명 두 배
```

해로운 효과(`lose_half_life`)가 있는 주문을 맞은 NPC는 시전자를 적으로 삼는다. 오라처럼 해롭지 않은 주문은 그렇지 않다.

**아이템** (`item`): 한곳에 서 있는 마법물체. 그곳에서 값을 치르고 1시간 들여 길들인 이(플레이어, NPC)의 것이 된다 (`sim/items.ts`). 주인이 죽거나 떠나면 다시 주인 없는 것이 된다.

```yaml
sim:
  cost: "{6}"
  at: loc-tazeem              # 서 있는 곳
  effects:
    - { type: charge_life }        # 길들일 때 그의 생명(반올림)을 담는다 (충전 카운터)
    - { type: landfall_set_life }  # 주인이 땅과 유대를 맺을 때, 담긴 생명이 더 크면 그만큼으로 (생명을 얻음)
```

## 요소 id 규칙

`<접두사>-<영문 슬러그>`. 파일 이름은 id와 같다.

| 종류 | kind | 접두사 | 예 |
|---|---|---|---|
| 장소 | `location` | `loc` | `loc-tazeem` |
| 생물 | `creature` | `cre` | `cre-baloth` |
| 인물 | `character` | `chr` | `chr-nissa-revane` |
| 세력 | `faction` | `fac` | `fac-joraga` |
| 아이템 | `item` | `itm` | `itm-khalni-gem` |
| 사건 | `event` | `evt` | `evt-roil` |
| 법칙 | `law` | `law` | `law-mana` |
| 주문 | `spell` | `spl` | `spl-blood-tribute` |

카드 id는 `<세트 코드>-<수집 번호>` (예: `ZEN-229`).

- `canon`: 확정된 설정
