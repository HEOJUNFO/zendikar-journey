# 세계관 (world/)

젠디카르 카드를 한 장씩 받아 세계관에 추가하며 쌓아가는 곳. 게임(저장소 루트)은 이 폴더를 원본으로 읽는다.

## 흐름: 카드 1장 → 세계관

1. **카드 기록**: `cards/<세트>-<번호>.md` 에 카드 원문(이름, 비용, 타입, 규칙 텍스트, 플레이버 텍스트)을 그대로 남긴다.
2. **해석**: 이 카드가 우리 세계에 무엇을 더하는지 정리하고, 사용자 확인을 받는다.
3. **요소 반영**: 새 요소는 `entities/<종류>/` 에 파일을 만들고, 기존 요소는 내용을 보강한다. 카드 파일의 `entities` 에 반영한 요소 id를 적는다. 지역이 필요한 카드면 location 에 `map` 을 달고 `npm run world:map` 을 실행한다.
4. **검사**: `npm run world:check` 로 형식과 참조를 확인한다.

## 카드 타입 → 요소 종류 (기본 대응)

| 카드 | 요소 종류 | 폴더 |
|---|---|---|
| 대지 | 장소 (지역, 자원) | `locations/` |
| 생물 | 생물종/몬스터 | `creatures/` |
| 전설적 생물, 플레인즈워커 | 인물 (NPC) | `characters/` |
| 부족/세력이 드러나는 카드 | 세력 | `factions/` |
| 마법물체, 장비 | 아이템 | `items/` |
| 순간마법, 집중마법 | 사건 또는 능력 | `events/` |
| 부여마법, 세계 규칙이 드러나는 카드 | 세계의 법칙 | `laws/` |

대응은 기본값일 뿐이다. 카드 한 장이 여러 요소를 만들거나 기존 요소를 보강만 할 수도 있다.

## 맵

젠디카르 행성은 **망망대해에서 시작**한다. 카드로 지역이 생길 때마다 그 location 에 `map` 을 달면 그 자리에 땅이 솟는다.

```yaml
map: { x: 48, y: 36, w: 24, h: 16, terrain: forest }
```

- `x`, `y`: 중심 타일 좌표. 맵 크기는 96×72 (x 0..95, y 0..71).
- `w`, `h`: 대략적인 너비와 높이(타일). 해안선은 자동으로 불규칙하게 만들어지고, 바닷가는 모래사장이 된다.
- `terrain`: `grassland` | `forest` | `rocky` | `beach` | `settlement` | `sky`.
  - `sky` 는 공중섬이다. 폐허 판석 바닥에 기둥, 헤드론, 돌무더기가 있고, 해변 대신 섬 주위의 바다가 하늘과 구름으로 바뀐다. 남쪽 가장자리에는 섬의 밑면이 보인다.
  - 정글, 늪, 용암, 설원처럼 젠디카르다운 다른 지형은 해당 카드가 나올 때 타일을 그려서 늘린다 (`tools/make-tiles.py`).
- 큰 지역 안에 작은 장소(마을 등)를 두려면 좌표를 겹치게 적는다. 작은 쪽이 위에 그려진다.
- location 하나가 NPC 일정에 쓰는 장소 하나가 된다. NPC가 설 자리(8곳)는 자동으로 고른다.

`npm run world:map` 으로 `data/zendikar.js`(게임 맵)와 `data/places.ts`(장소 목록)를 다시 만들고, 미리보기 `world/map.png` 를 그린다. 생성 파일은 직접 고치지 않는다.

아직 없는 것: 섬과 섬 사이 이동(배, 항로). 지금은 서로 떨어진 지역 사이를 걸어서 오갈 수 없다.

## 요소 id 규칙

`<접두사>-<영문 슬러그>`. 파일 이름은 id와 같다.

| 종류 | kind | 접두사 | 예 |
|---|---|---|---|
| 장소 | `location` | `loc` | `loc-tazeem` |
| 생물 | `creature` | `cre` | `cre-baloth` |
| 인물 | `character` | `chr` | `chr-nissa-revane` |
| 세력 | `faction` | `fac` | `fac-joraga` |
| 아이템 | `item` | `itm` | `itm-khalni-gem` |
| 사건 | `event` | `evt` | `evt-roil` |
| 법칙 | `law` | `law` | `law-mana` |

카드 id는 `<세트 코드>-<수집 번호>` (예: `ZEN-229`).

## status

- `draft`: 해석은 했지만 사용자 확인 전
- `canon`: 확정된 설정

## 템플릿

`_templates/` 의 파일을 복사해서 쓴다.

## IP 주의

젠디카르는 Wizards of the Coast의 IP다. 개인 프로젝트로는 괜찮다. 공개하거나 상용화하려면 이름과 설정을 우리 것으로 바꿔야 한다.
